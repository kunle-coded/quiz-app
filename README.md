# Quiz App

This is a simple quiz application built using HTML, CSS, and JavaScript. The app allows users to answer multiple-choice questions and provides feedback on their answers.

## Features

The Quiz App includes the following features:

- Multiple-choice questions
- Immediate feedback on answers
- Score tracking

### Installation

To run the Quiz App locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/kunle-coded/quiz-app.git
   ```
2. Navigate to the project directory:
   ```bash
   cd quiz-app
   ```
3. Open the `index.html` file in your web browser.

# Usage

1. Open the Quiz App in your web browser.
2. Read the question and select one of the multiple-choice answers.
3. Click the "Submit" button to check your answer.
4. The app will provide immediate feedback on whether your answer was correct or incorrect.
5. Continue answering questions until you have completed the quiz.
6. Your final score will be displayed at the end of the quiz.
